# MMM-ImmortalSchedule

A [MagicMirror²](https://magicmirror.builders/) module that displays upcoming class schedules from a public MyStudio scheduling endpoint.

Originally created for Immortal Martial Arts Center (Lewis Center), but configurable for any compatible MyStudio schedule.

## Features

- Displays upcoming classes on your MagicMirror
- Filters by favorite class names
- Removes past classes automatically
- Sorts classes chronologically
- Shows:
  - Class name
  - Start time
  - End time
  - Location
  - Optional capacity information
- Automatically refreshes on a configurable interval
